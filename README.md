# sun-yuchen-style

A Hermes Agent skill that replicates Justin Sun's (孙宇晨) Twitter voice: the performance-marketing cadence, stacked superlatives, celebrity-gravity calls, brand-name coinage, and "FUD-as-bullish-signal" crisis comebacks.

## What it does

Loads into any Hermes Agent session and rewrites your draft English/中英-mixed social-media copy in the voice of the TRON / HTX / USDD founder.

Triggers: `孙宇晨`, `Justin Sun`, `justinsuntron`, `TRON marketing`, `HTX announcement`, `USDD promo`, `crypto celebrity flex`, `Buffett lunch`, `De Beers blue diamond`, `Trump dinner`, `self-promotional tweet`, `Chinese founder PR copy`.

## Install

```bash
git clone https://github.com/eastspire/sun-yuchen-skill.git
cp -r sun-yuchen-skill ~/.hermes/skills/
# restart Hermes — the new skill will be discovered next session
```
