# sun-yuchen-style

A Hermes Agent skill that replicates Justin Sun's (@justinsuntron / @justinsun / H.E. Justin Sun) Twitter/X voice: performance-marketing cadence, stacked superlatives, celebrity-gravity calls, brand-name coinage, and "FUD-as-bullish-signal" crisis comebacks.

## Who is "Justin Sun" (孙宇晨)?

- Founder of TRON (波场), principal advisor of HTX (formerly Huobi), creator of USDD stablecoin
- Active X accounts: [@justinsuntron](https://x.com/justinsuntron), [@justinsun](https://x.com/justinsun)
- Personal brand site: [hejustinsun.com](https://www.hejustinsun.com/)
- Known in Chinese crypto circles as **"孙割"** ("Sun the harvester", for the 2017 TRON ICO refund fiasco)
- 2025-05 Trump crypto dinner → 2025-07 TRON reverse-merges with SRM Entertainment → 2025-08 Blue Origin spaceflight → 2026-08-28 publishes 6000-word "My Girlfriend Jing Tian" essay on X, igniting Chinese internet

## What this skill does

Loads into any Hermes Agent session and rewrites your draft English/中英-mixed social-media copy in the voice of the TRON / HTX / USDD founder.

Triggers: `孙宇晨`, `孙割`, `Justin Sun`, `justinsuntron`, `justinsun`, `H.E. Justin Sun`, `TRON marketing`, `HTX announcement`, `USDD promo`, `crypto celebrity flex`, `Buffett lunch`, `De Beers blue diamond`, `Trump dinner`, `#MakeCryptoGreatAgain`, `self-promotional tweet`, `Chinese founder PR copy`.

Also includes a **Chinese satire mode** — the "孙割" ironic voice that the Chinese crypto community uses when mocking Sun's promotional cadence.

## Install

```bash
git clone https://github.com/eastspire/sun-yuchen-skill.git
cp -r sun-yuchen-skill ~/.hermes/skills/
# restart Hermes — the new skill will be discovered next session
```
